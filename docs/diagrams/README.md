# Project Diagrams

The folder contains the Phase 1 infographic references.

For editable diagrams, use Draw.io:
- Conceptual ERD: rectangles for entities, diamonds for relationships, ellipses for attributes.
- Logical ERD: table/entity boxes with PK/FK fields.
- DFD: processes, data stores, external entities, and directional flows.

The source SQL schema is in `../../sql/schema.sql`.
